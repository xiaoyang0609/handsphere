# HandSphere 🌊

手势控制视觉球 —— 伸出手掌，操控一个绚丽的粒子球体在空间中旋转。

## 怎么玩

```
🖐 张开手掌 → 控制球体旋转方向
✊ 握拳     → 切换色彩主题（海洋→日落→极光→火焰）
⌨ 按空格/C  → 手动切换色彩（没摄像头时也适用）
```

## 启动方式

**方式一：用 Node.js 启动本地服务器（推荐）**

```bash
npx serve HandSphere
```

或者直接用我内置的 `http-server`:

```bash
cd HandSphere
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`

**方式二：直接用浏览器打开**

双击 `index.html` 打开即可。但注意：
- Chrome 可能不允许 `file://` 协议访问摄像头
- 建议用方式一启动本地服务器

## 技术栈

- **Three.js** — 3D 粒子渲染
- **MediaPipe Hands** — 手部关键点追踪
- **自定义粒子着色** — 8000 个粒子构成球体
- **斐波那契球面分布** — 粒子均匀分布
- **色彩渐变过渡** — 4 套主题平滑切换

## 效果

- 粒子球体跟随手掌旋转（平滑阻尼动画）
- 握拳触发色彩主题切换
- 粒子随手掌张开/闭合缩放
- 3 层轨道光环环绕旋转
- 背景星空
- 内层光晕脉动效果
